How the points work

Right answer: 20 + 80h, wrong: −(10 + 60(1−h)), with h = 1 − min(1, |max overlap − tau| / 0.5). So a call that sits right at the gate's threshold is worth the most, and a blunder on an obvious probe costs the most. The real gate is scored with the same rule. Wrong includes accepting a never-stored wave: the gate can be wrong too. The round list is generated from the run id, so a run is repeatable.

Break the gate

Goal: make the real gate accept a wave that is not one of the four stored experiences. Tap a neuron on the map to start a wave there, then dilute it with random noise. You score 10 × distance to the nearest stored seed + 100 × (1 − wave share) when the gate accepts a source at least 6 units away from every stored seed.

    The gate's threshold

    Gate rule: refuse when the best |overlap| with a stored experience is below tau. Calibrated once by MembraneBrain.calibrate (Youden's J on 100 noisy stored probes vs 100 random fields). Rates here are on a separate held-out set of 100 + 100.
